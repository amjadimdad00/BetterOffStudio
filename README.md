# BetterOff Clone 🎨

### A clone of the BetterOff Studio website built with NextJS and Tailwind CSS.

This project replicates the homepage design, layout, and animations of the original BetterOff Studio site.
⚠️ Note: The site is currently not fully responsive. Mobile and tablet views may not display correctly yet.

---

## ✨ Features

### 🖥️ Homepage

- ⚡ Animated landing area with interactive effects
- 🎨 Clean, modern design mimicking BetterOff Studio
- ✨ Smooth GSAP animations
- 🔹 Key sections: About, Services, Portfolio, Contact

### ⚠️ Limitations

- 📱 Not fully responsive
- 🌀 Some animations may need performance tuning
- 📝 Static content — no backend integration yet

---

## 🛠️ Tech Stack

- **Frontend:** Next.js, TypeScript
- **Styling:** Tailwind CSS
- **Animations:** GSAP
- **Build Tool:** Vite

---

## ⚡ Installation

### Clone repo

```bash
git clone https://github.com/amjadimdad00/BetterOffStudio
cd BetterOffStudio
```

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
